# 더뉴 BMW X5 G65 마케팅 브리프

| 메시지 | 주요 채널 | 유도할 행동 |
|---|---|---|
| SUV를 고를 때도, 운전의 즐거움은 X5. | 유튜브 쇼츠와 인스타그램 릴스 | 40 xDrive의 모델 정보를 확인한다. |
| 보고 싶은 운전 정보, 내 눈앞에 내 방식대로. | 인스타그램 카드뉴스 | 파노라믹 iDrive의 기능 설명을 읽는다. |
| 일상에 전기 주행을 더하다, X5 50e. | 검색 유입용 블로그와 랜딩 페이지 | 50e의 모델 정보와 충전 조건을 확인한다. |

이 브리프는 [메시지 제안서](marketing_messages.md)의 구매 이유와 문구를 유지한 제작 제안이다. 핵심 고객과 채널 선택은 조사 자료를 바탕으로 세운 가설이다. 자료 확인일은 2026년 10월 30일에서 11월 2일 사이이며 신규 사실 조사는 포함하지 않았다.

## 1. 가솔린 모델의 주행 반응

### 활용 방향

핵심 고객은 SUV를 고를 때도 가속과 조향 반응을 중요하게 보는 구매자다. 30초 세로 영상으로 운전 감각에 관심을 끌고 40 xDrive의 공식 모델 설명으로 연결한다. 차량 전체의 인상을 보여 주되 성능 수치는 해당 모델과 함께 표시한다.

메시지는 그대로 사용한다.

SUV를 고를 때도, 운전의 즐거움은 X5.

### 콘텐츠 구성

| 구간 | 내용 | 제작 지시 |
|---|---|---|
| 0~5초, 고객의 고민 | SUV를 고르면서 운전 감각도 놓치고 싶지 않다는 상황을 제안한다. | 도입 자막은 "SUV를 고를 때, 운전 감각도 보시나요?"로 쓴다. |
| 5~13초, 제품의 특징 | 40 xDrive의 힘과 주행 반응을 소개한다. | 사용 허가를 받은 해당 모델의 주행 장면에 모델명을 표시한다. |
| 13~23초, 근거와 설명 | 공식 소개의 400마력과 0~100km/h 5.3초를 보여 준다. | 화면에 출처와 해외 소개 사양 기준이라는 조건을 함께 둔다. |
| 23~30초, CTA | 기존 메시지와 모델 정보 확인 버튼으로 마무리한다. | CTA는 "X5 40 xDrive 알아보기"로 쓴다. |

근거는 [BMW 공식 소개](https://www.bmw.co.kr/ko/all-models/x-series/suv/bmw-x5.html)와 [Edmunds 단기 시승기](https://www.edmunds.com/car-news/2027-bmw-x5-ix5-first-drive-review.html)다. 기자는 힘과 부드러운 변속, 조향 피드백을 긍정적으로 평가했다. 시승차는 에어 서스펜션을 장착했으며 모든 사양의 승차감을 검증한 결과는 아니다.

### 제작 가이드

짧은 질문과 구체적인 제품 설명으로 문장을 쓴다. 빠른 편집이나 과장된 엔진음으로 가속 성능을 부풀리지 않고 합법적인 주행 장면을 선택한다. 정지 이미지를 주행 영상처럼 보이게 가공하지 않는다.

색은 흰색과 짙은 회색을 기본으로 제안한다. 수치는 배경과 대비되게 배치하고 출처와 조건을 읽을 수 있는 크기로 표시한다. 이 색 구성은 BMW 공식 규정으로 확인된 값이 아니다.

현재 보유한 [공식 외관 이미지](../../../brand/BMW/더뉴%20BMW%20X5%20G65/assets/bmw-g65-exterior.webp)는 표지와 영상 기획 참고에 사용할 수 있다. 실제 주행 장면은 별도 확보가 필요하다. "동급 최고 가속", "GLE보다 빠른 SUV", "어떤 노면에서도 편안함"은 근거가 없어 쓰지 않는다.

## 2. 운전 정보의 표시와 개인 설정

### 활용 방향

핵심 고객은 디지털 실내를 선호하고 필요한 운전 정보를 원하는 위치에 배치하고 싶은 구매자다. 인스타그램 카드뉴스 5장으로 기능을 차례로 설명하고 프로필 또는 스토리 링크에서 공식 기능 안내를 읽도록 유도한다. 카드 이미지 안의 주소를 클릭할 수 있는 버튼처럼 표현하지 않는다.

메시지는 그대로 사용한다.

보고 싶은 운전 정보, 내 눈앞에 내 방식대로.

### 콘텐츠 구성

| 카드 | 내용 | 제작 지시 |
|---|---|---|
| 1, 고객의 고민 | 필요한 정보가 어디에 표시되는지 궁금한 구매자를 대상으로 시작한다. | 도입 문구는 "운전할 때 보고 싶은 정보는 무엇인가요?"로 쓴다. |
| 2, 제품의 특징 | 파노라믹 비전의 정보 표시 위치를 소개한다. | 위치와 화면의 관계를 실제 해당 모델 자료로 보여 준다. |
| 3, 제품 설명 | 중앙 화면의 위젯을 파노라믹 비전으로 옮기는 기능을 설명한다. | 정차 상태의 검증된 시연 자료를 사용한다. |
| 4, 근거와 조건 | 공식 기능 안내와 정차 체험자의 표시 선명도 평가를 요약한다. | 국내 제공 기능과 트림별 구성이 미확인임을 표시한다. |
| 5, CTA | 메시지를 다시 보여 주고 기능 설명으로 연결한다. | CTA는 "파노라믹 iDrive 알아보기"로 쓴다. |

근거는 [공식 기능 안내](https://www.bmw.co.kr/ko/all-models/x-series/suv/bmw-x5.html)와 [Edmunds 정차 체험기](https://www.edmunds.com/car-news/2027-bmw-x5-hands-on-first-look.html)다. 정차 체험자의 평가를 운전 중 안전성이나 조작 시간의 측정 결과로 표현하지 않는다. 고객 자료에는 물리 조작부가 없는 점을 불편하게 느낀 의견도 있다. [고객의 시승 경험](https://www.reddit.com/r/BMWiX/comments/1x3pu3n/test_drove_the_new_2027_x5_in_prep_for_ix5/)

### 제작 가이드

문체는 기능을 한 번에 하나씩 설명하는 방식으로 쓴다. "화면에서 위젯을 선택합니다"처럼 행동을 구체적으로 적되 실제 시연을 확인한 조작만 설명한다. 움직이는 차량에서 화면을 조작하는 장면은 구성하지 않는다.

흰 배경과 짙은 회색 글자를 기본으로 제안하고 선택한 정보 위치는 테두리나 화살표로 표시한다. UI의 색과 숫자는 원본을 유지한다. 브랜드의 공식 UI를 임의로 다시 그려 실제 기능처럼 제시하지 않는다.

보유한 [계기와 HUD 예시 이미지](../../../brand/BMW/더뉴%20BMW%20X5%20G65/assets/bmw-g65-cockpit.webp)는 위젯 이동 시연을 확인한 자료가 아니다. 추가 시연 자료를 확보하기 전에는 카드 3을 설명 문안으로만 구성한다. 이미지 속 48km/h와 905km는 예시 표시값이므로 성능이나 주행거리로 쓰지 않는다. "눈을 떼지 않아도 되는 운전", "누구나 바로 익숙해지는 조작", "경쟁차보다 안전한 화면"은 쓰지 않는다.

## 3. 50e의 전기 주행

### 활용 방향

핵심 고객은 집이나 직장에서 충전할 수 있고 평소 이동에 전기 주행을 활용하려는 구매자다. 검색 유입용 블로그에서 플러그인 하이브리드를 설명하고 랜딩 페이지에서 50e의 제공 조건을 확인하도록 연결한다. 국내 판매 조건이 확인되기 전에는 즉시 계약이나 인도를 약속하지 않는다.

메시지는 그대로 사용한다.

일상에 전기 주행을 더하다, X5 50e.

### 콘텐츠 구성

| 순서 | 내용 | 제작 지시 |
|---|---|---|
| 고객의 고민 | 기존 이동에 전기 주행을 더하고 싶지만 충전 조건을 먼저 알고 싶은 상황을 제안한다. | 도입 문구는 "내 생활에 플러그인 하이브리드가 맞을까요?"로 쓴다. |
| 제품의 특징 | 가솔린 엔진과 전기 모터를 함께 쓰는 50e를 소개한다. | 제목과 이미지 설명에 "X5 50e"를 표시한다. |
| 근거와 설명 | 공식 소개의 WLTP 전기 주행거리 92~102km를 설명한다. | 수치 옆에 "WLTP 기준, 국내 인증값 및 실제 주행거리와 다를 수 있음"을 표시한다. |
| 사용 조건 | 충전할 장소와 국내 충전 규격, 제공 장비를 확인할 항목으로 제시한다. | 확인되지 않은 출력과 케이블 구성은 미확인으로 둔다. |
| CTA | 공식 모델 설명과 실제 국내 제공 조건을 확인하도록 안내한다. | CTA는 "X5 50e 모델 정보 확인하기"로 쓴다. |

근거는 [BMW 50e 공식 소개](https://www.bmw.co.kr/ko/all-models/x-series/suv/bmw-x5.html)다. WLTP는 정해진 시험 조건에서 측정하는 기준이며 실제 도로의 주행거리를 보장하지 않는다. [고객 분석](../../../customer/BMW/더뉴%20BMW%20X5%20G65/customer.md)의 충전 질문은 이전 세대 G05 자료이므로 G65의 실사용 후기로 인용하지 않는다.

### 제작 가이드

전기차와 플러그인 하이브리드의 차이를 이해할 수 있게 쓴다. 전기 주행을 원하는 생활과 충전 전제를 함께 설명하고 집에 충전기가 없는 고객에게도 같은 이점을 약속하지 않는다.

흰색과 짙은 회색을 기본으로 제안한다. 순수 전기차처럼 보이게 만드는 시각 표현을 피하고 50e 모델명을 본문과 이미지에 일관되게 표시한다. [공식 PHEV 이미지](../../../brand/BMW/더뉴%20BMW%20X5%20G65/assets/bmw-g65-phev.webp)는 참고 에셋으로 연결한다.

"출퇴근은 무조건 전기로", "한 번 충전으로 102km 보장", "충전 걱정 없음", "유지비 절반", "무배출 자동차"는 쓰지 않는다. 가솔린 40 xDrive 이미지나 제원을 50e에 섞지 않는다.

## 공통 브랜드 및 제작 기준

프로젝트에는 BMW의 `brand.md`, 공식 컬러 규격, 로고 원본과 사용 지침이 없다. 아래 기준은 제작 제안과 확인 항목이며 공식 브랜드 가이드를 대신하지 않는다.

| 항목 | 적용 기준 |
|---|---|
| 문체 | 구체적인 기능과 사용 장면을 짧게 설명하고 과장된 최상급 표현을 피한다. |
| 컬러 | 흰색과 짙은 회색을 임시 기본색으로 쓰고 공식 가이드 확보 후 실제 색상값을 확정한다. |
| 로고 | 승인된 BMW 로고 원본과 매체별 지침을 확보한 뒤 크기와 여백을 적용한다. |
| 슬로건 | 세 제안 문구를 캠페인 메시지로 사용하고 BMW의 공식 슬로건으로 표기하지 않는다. |
| 서체 | 한국어 가독성을 확보한 임시 서체로 시안을 만들고 공식 지정 서체와 라이선스는 별도 확인한다. |
| 에셋 | [출처와 권리 기록](../../../brand/BMW/더뉴%20BMW%20X5%20G65/assets/sources.json)을 확인하고 공개용 제작에는 사용이 허가된 자료를 적용한다. |
| CTA | 현재 연결할 주소는 [BMW 공식 모델 페이지](https://www.bmw.co.kr/ko/all-models/x-series/suv/bmw-x5.html)이며 예약과 판매 링크는 실제 제공 여부를 확인한 뒤 적용한다. |

로고는 임의로 다시 그리거나 색을 바꾸지 않는다. 이미지 속 차량 엠블럼을 잘라 공식 서명 로고 대신 쓰지 않는다. 기존 공식 이미지도 상업적 재사용 권한은 미확인이므로 확보한 파일을 곧바로 광고에 사용할 수 있다고 판단하지 않는다.

고객 후기나 전문 시승의 문장을 광고에 직접 넣으려면 원문과 인용 범위, 사용 조건을 확인한다. 판매자 경험을 일반 차주 추천으로 바꾸거나 개별 불만을 경쟁차의 일반 결함으로 제시하지 않는다.

## 제작 전 확인 항목

- 국내 출시와 제공 트림, 메시지별 기능 및 제원 적용 여부를 확인한다.
- 가격과 선택 옵션, 디지털 구독료를 표기할 경우 해당 계약 조건과 확인일을 함께 확보한다.
- 주행과 UI 시연에 쓸 해당 모델 영상, 브랜드 가이드와 에셋 사용 권한을 확보한다.
- 공개 채널의 링크와 상담 또는 시승 예약 가능 여부를 확인한다.

비교 자료는 [competitor.md](../../../competitor/BMW/더뉴%20BMW%20X5%20G65/competitor.md)를 따른다. 조사에 쓰인 연식과 시장, 옵션이 달라 경쟁차보다 빠르거나 저렴하다는 표현과 보증 및 내구성의 우위는 현재 근거로 확정하지 않는다.
