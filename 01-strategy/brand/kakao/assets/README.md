# 카카오 브랜드 에셋

| 파일 | 출처 | 사용 조건과 범위 |
| --- | --- | --- |
| `Kakao_CI_official_noncommercial.png` | [카카오 공식 CI 페이지](https://www.kakaocorp.com/page/detail/11340) | 페이지는 제공 자료의 상업적 이용을 금지한다. 별도 브랜드 보호 정책은 제3자 사용에 사전 승인을 요구한다. |
| `Kakao_Big_Small_Sans_OFL_source.zip` | [카카오 공식 폰트 GitHub](https://github.com/kakao/kakao-font) | OFL-1.1. 사용·수정·재배포 전 압축 안의 OFL.txt를 확인한다. |

로고 파일을 내려받을 수 있다는 사실이 브랜드 사용 허가를 뜻하지 않는다. CI는 조사 참고용으로만 보관했다. 이미지, 캐릭터, 사운드 자료는 재사용 조건을 확인하지 못해 별도로 복사하지 않고 공식 링크만 문서에 남겼다.
