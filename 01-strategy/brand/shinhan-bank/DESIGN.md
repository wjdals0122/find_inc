# 신한은행 디자인 시스템 조사 기록

> 공개 자료를 정리한 참고 문서다. 신한은행이 승인한 사용 매뉴얼이 아니다. 은행 VI 프로젝트 내용과 신한금융그룹 CI 규정을 구분한다.

## 브랜드 방향

| 항목 | 확인 내용 | 출처 구분 |
| --- | --- | --- |
| VI 개념 | Embracing Forward, ‘포용적인 전진’ | 공동 자료 제공 프로젝트 소개, 정식 가이드 아님 |
| 기본 모티프 | 신한은행 원형 심볼에서 확장한 Circle과 Line | 프로젝트 설명. 새 로고 모양으로 단정하지 않음 |
| 그래픽 전개 | Line, Solid, Gradient | 프로젝트 설명 |
| 활용 방향 | 디지털·인쇄·오프라인 접점에서 시각 일관성을 갖춘 시스템 | 프로젝트 설명 |

## 로고

### 신한은행

- VI 전용 원본 로고, 조합형, 최소 크기, 여백, 배경별 적용과 변형 금지 규정: **미확인**
- 공개된 Circle·Line 설명은 그래픽 모티프에 대한 것이다. 로고 자체의 구조와 동일시하지 않는다.
- 외부 이용 범위와 허가 조건: **미확인**

### 신한금융그룹 참고

공식 그룹 CI 사이트에서 심볼마크, 국·영문 로고타입, 좌우·상하 시그니처를 제공한다. 다운로드 파일은 `assets/`에 보관했다. 신한은행 전용 로고로 사용하지 않는다.

## 이미지와 그래픽

- 은행 사진·일러스트의 주제, 구도, 보정 기준: **미확인**
- Circle·Line 모티프와 Line·Solid·Gradient 그래픽 체계는 VI 프로젝트 소개에서 확인했다. 치수나 조합 규칙은 미확인.
- 신한은행 ESG 스토리북에서 신한프렌즈와 현장 사진을 활용했다. 이 자료의 콘텐츠 사례이며 전사 이미지 규정은 아니다.

## 사용 시 참고할 점

- `assets/`의 CI 파일은 신한금융그룹 제공 자료다. 신한은행 VI 원본으로 바꿔 쓰지 않는다.
- 그룹 공식 페이지는 에셋을 제공하지만 외부 이용 허가 조건을 별도로 확인하지 못했다.
- 신한은행 VI 신규 색상과 서체 사양은 프로젝트 소개에 숫자나 글꼴명이 나오지 않는다. 이 문서에서 임의로 보정값을 만들지 않았다.
