# 제품 연출 컷 그리드

브랜드와 상품의 실제 참고 자료를 바탕으로 제품의 형태·색상과 일관된 연출 컷을 만든다. 사용자 지정 조건이 있으면 아래 기본값보다 우선한다.

## 자료 확인

1. 대화에서 브랜드와 상품을 확인하고, 이름·모델·세대가 같은 자료를 찾는다. 지정이 없으면 다음 경로를 먼저 확인한다.
   - 제품 이미지: `01-strategy/brand/<브랜드명>/<상품명>/assets/`
   - 마케팅 브리프: `01-strategy/brief/<브랜드명>/<상품명>/brief.md`
   - 브랜드 색상·로고 규칙과 이미지 출처·권리 기록이 있으면 함께 읽는다.
2. 브리프의 핵심 메시지, 표현 조건, 확인되지 않은 사양을 파악한다. 시각적으로 확인 가능한 제품 사진을 열어 제품 형태·색상·식별 요소를 살핀다. 텍스트 설명만으로 제품 외형을 지어내지 않는다.
3. 관련 이미지가 여럿이면 모델·색상·트림과 각 사진의 역할을 구분해 사용할 참조를 고른다. 다른 모델의 사진을 디테일 참조로 쓴다면 그 차이를 밝히고 확인되지 않은 사양을 사실처럼 표현하지 않는다. 핵심 제품 이미지가 없거나 상품을 특정할 수 없으면 무엇이 필요한지 묻는다. 브리프가 없으면 그 사실을 알리고 확인 가능한 자료로 진행하되 전략을 지어내지 않는다.

## 생성과 수정

- `imagegen` 스킬의 현재 `SKILL.md`를 읽고 내장 이미지 생성 도구를 사용한다. 사용자가 CLI/API 방식을 명시하거나 확인한 경우에만 그 경로를 사용한다. 사진은 시각적으로 확인한 뒤 도구가 지원하는 참조 입력으로 전달한다.
- 기본 산출물은 **세로 9:16 이미지 한 장**, **동일한 크기의 3열 × 3행**, **그리드 사이 간격 최소화**다. 제품 전체를 여러 각도에서 보여 주는 컷과 특징적인 디테일을 섞고, 아홉 칸 모두 같은 제품과 색상으로 보이게 한다. 제품 종류에 맞는 각도와 디테일을 선택한다.
- 배경은 제품색과 확인된 브랜드 컬러, 브리프의 방향에 어울리게 정한다. 공식 색상 규격이 없으면 제작용 색상 제안으로 다루고 공식 규정이라고 주장하지 않는다. 텍스트·수치·로고·효과는 사용자가 요청하거나 근거가 있을 때만 넣는다.
- 제품의 실루엣과 핵심 식별 요소를 참조에 맞춘다. 사진에서 확인할 수 없는 각도·구성·UI·기능은 창작된 연출일 수 있으므로 확정 사양으로 제시하지 않는다. 브리프가 금지하는 과장이나 서로 다른 모델·사양의 혼합을 피한다.
- 사용자가 최고 모델·해상도를 요청하면 현재 사용 가능한 생성 도구의 최대 품질을 요청한다. 도구가 모델·출력 크기를 선택할 수 없으면 임의로 다른 경로로 전환하지 말고, 실제로 확인된 크기와 제한을 보고한다. 9:16이 맞지 않으면 이미지 도구로 재시도하고 실제 픽셀 비율을 확인한다. 여전히 정확하지 않으면 실제 비율을 밝힌다.
- 사용자가 수정 사진을 제공하면 기존 생성물은 **편집 대상**, 새 사진은 **수정할 부위의 참조**로 명시한다. 사용자가 지정한 부분만 수정하고 기존 구도·색상·다른 컷은 유지하도록 요청한다. 참조 사진의 모델이나 버전이 다르면 해당 차이도 결과에 알린다.

## 검토와 저장

1. 생성 결과를 직접 확인한다. 9개 칸, 제품 일관성, 참조와 다른 디테일, 잘림·잘못된 문자, 간격과 비율을 점검한다. 결과가 요청과 다르면 필요한 부분을 명확히 지정해 다시 생성하거나 수정한다. 확인되지 않은 특징은 미확인으로 남긴다.
2. 기본 저장 위치는 `02-contents/assets/<브랜드명>/<상품명>/product-shot1.png`다. [콘텐츠 제품 컷 저장 가이드](../../../docs/guides/content-assets.md)를 따른다. 동일 이름의 기존 파일은 덮어쓰지 않고 `product-shot1-v2.png`처럼 다음 버전으로 저장한다. 사용자가 기존 파일을 교체하라고 명시한 경우에는 그 지시를 따른다.
3. 실제 저장 파일의 형식과 픽셀 크기를 확인한다. 사용자에게 파일 경로, 실제 크기·비율, 사용한 생성 방식과 프롬프트를 알린다. 생성 이미지에서 추정한 형태와 참고 이미지의 사용 권한이 확인되지 않은 경우 이를 구분해 알린다. 별도 요청 없이 공개·배포하거나 외부에 전송하지 않는다.
