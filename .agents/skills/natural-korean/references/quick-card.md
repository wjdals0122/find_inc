# 한국어 요약 카드

결정 페이지, 계획, 긴 문서를 쓰거나 고칠 때는 이 카드만 보지 말고 `references/writing-procedure.md`와 `SKILL.md`를 끝까지 읽는다.

## 사용자 원칙 (원문, 고치지 않는다)

1. 영어 문장 구조를 직역한 표현과 영어식 관용구를 사용하지 마세요.
2. 불필요한 비유, 수사적 표현, 현학적인 어휘를 피하세요.
3. 추상적인 명사보다 구체적인 동사와 직접적인 설명을 우선하세요.
4. 전문적인 내용이라도 한국인 엔지니어가 동료에게 설명하듯 명확하게 작성하세요.
5. 한국어 원어민이 일상적으로 쓰지 않는 표현은 더 자연스러운 문장으로 바꾸세요.
6. 출력 직전에 어색한 번역투와 불필요한 수식을 점검하고 수정하세요.
7. 간결함을 위해 중요한 근거나 기술적 세부사항을 생략하지 마세요.

## 형식

- 목록의 한 항목과 표의 한 칸에는 한 문장만 쓴다.
- 사용자에게 보내는 보고와 답변은 존댓말(합쇼체나 해요체)로 쓰고, "~한다", "~했다"로 끝내지 않는다.
- 가운데 점(·), 줄표(—), en dash(–)를 쓰지 않는다. 쉼표, 괄호, 문장 나누기로 바꾼다.
- 줄 맨 앞의 굵은 머리말(`**핵심:**`)과 문단을 여는 굵은 문장을 쓰지 않는다.
- 이모지와 문장 끝 물결표를 쓰지 않고, 곡선 따옴표는 다른 흔적과 겹칠 때만 고친다.
- 문장은 주어와 동사를 갖춰 쓰고, 독자가 겪는 일(실패, 비용, 달라지는 점)을 먼저 적는다.
- 문장은 10세 아이가 읽을 수 있게 한 문장에 한 가지만 쉬운 낱말로 쓰고 AI에 주는 영어 지시문(판정, 교정, 생성 프롬프트)에도 같은 기준을 적용한다.
- 띄어 쓰는 보조용언은 붙이지 않는다(예: "시도해주세요"가 아니라 "시도해 주세요").
- 마크다운 문서의 산문은 글자 수로 폭을 맞추지 않고 문장이 끝나는 자리에서만 줄을 바꾸며 기존 문서를 고칠 때 한 줄이던 항목을 문장마다 여러 줄로 쪼개지 않는다.

## 반드시 지울 것 (S1, 횟수를 적은 항목은 그 횟수부터)

- A-1~3: "~에 대해", "~를 통해", "~에 있어서"
- A-7: "가지고 있다" 직역
- A-8: 이중 피동 "되어진다", "보여진다"
- A-16: "그/그녀/그것/그들"을 한 단락에 3번 넘게
- C-5: 이모지 장식
- C-10: "X: Y" 콜론 부제 제목 반복
- C-11: 연결어미(-고, -며, -지만) 바로 뒤 쉼표
- C-12: 지어낸 소제목, 블록 이름, 표 머리
- D-1: "결론적으로", "따라서", "요약하면" 같은 결산 접속(3번 초과)
- D-2: "시사하는 바가 크다", "주목할 만하다"
- D-3: "본질적으로", "핵심적으로"
- D-4: 과장어(획기적, 압도적, 진정한, 자리매김) 3번 이상
- D-5: 사물 주어 의인화("기술이 묻는다")
- D-6: "~할 때다", "~해야 한다"로 닫는 마무리, 막연한 긍정 마무리
- D-8: 이정표, 새 지평 같은 과장된 의의
- H-1: 문장 첫머리 "또한, 나아가, 게다가" 5번 이상
- H-3: "이는", "이 점에서" 3번 이상
- I-1: "~인 것이다" 결말
- J-1: 문단을 여는 굵은 문장
- J-2: 줄표(—, –)
- K-1~2: 챗봇 응대, 아첨
- K-3: 글을 쓴 과정 설명

## 표현

- 비유로 지은 명사(관문, 게이트, 출고, 안전망, 좁히다)는 실제 동작으로 푼다.
- 번역투 예: "시간선이 맞습니다"는 "발생 시점이 일치합니다", "요청이 걸리지 않았습니다"는 "불러오지 못했습니다", "색이 정보를 나릅니다"는 "색으로 구분합니다"로 쓴다.
- 사물을 사람처럼 쓰지 않는다("코드가 죽었습니다" 대신 "쓰지 않는 코드입니다").
- 개발 용어(배포, 호출, 캐시, 의존성)와 외래어(프롬프트, 토큰, 커밋)는 우리말로 바꾸지 않는다.
- API 키, 토큰, 웹훅 주소는 "인증 정보" 또는 구체적인 이름으로 쓴다.
- 제목, 화면 라벨, 표 머리, 칩, 버튼은 모든 글에서 "실패 시 처리", "입력"처럼 짧은 명사형 표준 표기로 쓴다.
- "손실이 나온 곳", "지금 추세면 목표일에" 같은 문장형 제목과 질문형 제목은 쓰지 않는다.
- "곳" 같은 기계 번역어와 "지금" 같은 시점 부사는 라벨에 쓰지 않는다.

## 그대로 둘 것

- 숫자, 날짜, 이름, 코드 이름, 파일 경로, 환경변수 이름은 한 글자도 바꾸지 않는다.
- 큰따옴표 안의 문구(사용자 인용, 확정 문구)와 "그대로 들어갈 문장" 표시가 붙은 블록은 고치지 않는다.
- 사실 목록의 표준 용어를 일상어로 바꾸지 않는다.

## 끝내기 전에

- `python3 "<설치된 스킬 폴더>/scripts/check-korean.py" --skip-code --skip-quotes <파일>`을 돌려 나온 줄을 고친다.
- 소리 내어 읽었을 때 한국 동료가 회의에서 말해도 어색하지 않은지 본다.
