# Remember project rules

Use this skill when the user asks you to remember rules they want followed in future project work.

Follow [the rule memory guide](../../../docs/guides/rule-memory.md). In particular, check existing guides and `AGENTS.md` first, merge duplicate rules, and ask the user before changing anything that conflicts with an existing rule. Record important decisions using [the decision recording guide](../../../docs/guides/decision-recording.md). Preserve unrelated content and report the files changed.
