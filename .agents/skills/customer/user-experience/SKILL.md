# 사용 경험 조사

우리 상품과 경쟁 상품을 나누고 모델·세대·사용 기간·시장·옵션·환경을 확인한다. 소유자의 사용, 전문가의 단기 시승, 정차 체험, 판매자의 이해관계를 구별한다. 실제 원문과 출처를 붙여 장점과 아쉬움을 상황별로 적는다. 개인 불만을 결함률로, 이전 세대나 경쟁차 경험을 우리 상품의 경험으로 일반화하지 않는다. 광고·협찬 여부를 확인하지 못하면 미확인으로 표시한다.
