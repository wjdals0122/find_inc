# Meta 광고 무료 수집 절차

## 검색과 상태 확인

Meta 광고 라이브러리에서 국가와 활성 상태, 검색어 또는 광고주 페이지를 설정한다. 직접 접근이 제한되면 원본 URL 앞에 `https://r.jina.ai/`를 붙여 무료 Reader HTTP 경로로 요청한다. 예를 들어 검색 URL의 쿼리는 원본 URL로 유지한다. 셸에서 `&`가 실행되지 않도록 URL 전체를 인용한다.

```powershell
$url = 'https://www.facebook.com/ads/library/?active_status=active&ad_type=all&country=KR&q=GLE&search_type=keyword_unordered'
curl.exe -L --fail --max-time 60 ('https://r.jina.ai/' + $url)
```

Reader는 제3자 서비스이므로 공개 URL만 보낸다. 토큰, 쿠키와 비공개 정보를 URL에 넣지 않는다. Reader가 접근·렌더링을 항상 보장하지 않으며 캐시될 수 있다. 응답의 원본 URL, 최종 URL, 실제 국가와 활성 필터, 카드별 `Library ID`와 `Active`/`Inactive`, 광고주 및 확인 시각을 대조한다. ID 링크는 `https://www.facebook.com/ads/library/?id=광고ID`로 기록하되 단일 광고 페이지가 실제로 열리는지 별도로 확인한다. 확인이 안 되면 검색 결과에서 본 사실과 분리해 표시한다. 표시된 숫자와 실제 불러온 카드 수는 다를 수 있으며, 필요한 범위가 모두 보이지 않으면 부분 수집이다.

HTTP 200만으로 성공이라 판단하지 않는다. CAPTCHA, challenge, 로그인·차단 화면, 오류 문구, 빈 페이지, 필터 미적용, 광고 카드 미표시는 접근 실패 또는 불완전 응답이다. 명시적 0건 결과가 정상 화면과 올바른 필터에서 확인된 경우만 결과 없음이다. 검색엔진 설명은 후보일 뿐 활성 상태의 증거가 아니다.

## 이미지 확보

Reader의 텍스트에 소재가 빠질 수 있다. 동일한 검색 URL에 `X-Respond-With: html` 헤더로 렌더링된 HTML을 받아 해당 ID와 같은 광고 카드 안의 이미지 요소와 URL을 살핀다.

```powershell
curl.exe -L --fail --max-time 60 -H 'X-Respond-With: html' ('https://r.jina.ai/' + $url) -o meta-rendered.html
```

DOM 구조가 바뀔 수 있으므로 주변 카드의 광고주·카피·ID와 이미지의 연결을 직접 검증한다. 카드 순서만으로 연결을 확정하지 않는다. 프로필 이미지와 광고 소재를 구분하고 여러 장이면 각 장을 보관한다. 소재 URL을 HTML 엔터티 디코딩해 원본 URL 그대로 다운로드한다. HTTP 상태, 실제 이미지 형식과 확장자, 크기, 파일 열기 및 광고 내용과의 시각적 일치 여부를 확인한다. 광고 소재의 리사이즈본이면 그렇게 기록한다. 이미지가 보이지 않거나 링크가 만료되면 실패로 기록하고 화면 전체 캡처나 프로필 이미지를 원본 소재로 바꿔치기하지 않는다. 캡처가 요청되거나 필요한 경우 소재와 별도로 식별한다.

파일과 보고서에 원본 광고 링크, 이미지 URL, 수집 경로, 수집·확인 시각과 확보 범위를 적는다. 외부 URL의 서명 값이나 접근 권한이 포함될 수 있으므로 공개 기록 전 민감한 값이 없는지 확인한다. 영상 프레임은 정지 이미지 광고라고 부르지 않는다.

2026-11-09 검증: 한국·활성 GLE 검색의 Reader 텍스트와 HTML에서 ID 2053837422059730 및 활성 상태를 확인했다. 같은 카드의 리렌트레이드 소재 중 600×600 JPEG 한 장을 다운로드하고 이미지로 열었다. 카드에는 여러 소재가 있었으며, 이 시험은 해당 검색 조건 전체 수집이나 다른 광고주의 소재 접근을 보장하지 않는다. 해당 ID의 단일 광고 HTML 요청은 보안 확인 화면을 반환했다.
