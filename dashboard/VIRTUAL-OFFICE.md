# Virtual Office

상단 `Virtual Office` 버튼으로 기존 리포트와 전체 화면 오피스를 전환한다. Computer Use 없이 소스·Playwright 자동화·HTTP 응답으로 검증한다.

- 실제 화면: http://127.0.0.1:8000/dashboard.html (기존 Firebase 로그인 필요)
- 연출 프리뷰: http://127.0.0.1:8000/virtual-office-preview.html (명시적인 샘플 데이터, 작업 실행 없음)
- 시작: 프로젝트 루트에서 `python dashboard/serve.py --port 8000`
- 검증: `node dashboard/tests/virtual-office.cjs`

## 작업 연결

기존 SkillsPanel의 인증된 Happier Cloud API 응답을 `studio-skill-runs` 이벤트로 전달한다. 오피스를 열면 히스토리를 불러오고 미완료 세션을 최대 3개씩 병렬 조회한다. 한 차례 조회가 끝난 뒤 6초 후 다시 확인한다. 스킬 실행 창이 닫혀 있어도 추적하며, 오피스를 닫거나 문서가 숨겨지면 정기 조회를 멈춘다. 로그인 상태와 기존 Cloud 기기 연결을 유지한다. 실제 Codex 실행은 기존 스킬 스튜디오에서 한다.

명시적인 `agentId`, `agent.id`, `agentKey`가 있으면 그것을 캐릭터 식별자로 쓴다. 현재 실행기가 해당 필드를 제공하지 않는 경우 스킬의 담당 역할로 묶는다. 예를 들어 brand/product/crawler는 브랜드 리서처 캐릭터 하나에 여러 세션으로 표시한다. 초기 직원 캐릭터는 담당 역할 자리 표시이며 실행된 세션으로 계산하지 않는다. 사용자가 직접 이 대시보드에서 실행한 내역만 연결한다. 외부 Codex 앱의 모든 세션이나 내부 하위 에이전트를 발견하는 서비스는 설치하지 않는다.

실제 세션 상태·진행 응답·결과·오류는 오른쪽 상세 패널에 표시하며 말풍선에는 짧게 표시한다. 완료 전환을 확인한 담당자는 라운지로 이동해 쉬고 동료와 대화한 뒤 자리로 돌아온다. 다른 진행 세션이 있으면 계속 작업한다. 대화 문구는 연출이며 실제 에이전트 발언으로 기록하지 않는다. 담당 부서가 바뀌는 동일 에이전트는 복도를 지나 엘리베이터로 이동한다. 로그아웃 시 캐릭터의 작업 연결·결과·타이머를 비운다. 작업 내용은 이 모듈에서 로컬 저장소에 추가 저장하지 않는다.

## 공간과 렌더링

각 층 상단에는 부서 색상의 층 배지(예: `3F 전략`)와 색상 띠를 둬 층을 한눈에 구분한다. 4F는 우드 바닥과 대형 스크린·소파 좌석이 있는 전사 타운홀 라운지, 3F는 세이지 카펫·책장·자료 선반의 리서치 라이브러리, 2F는 우드·컬러 러그·빈백·팔레트 보드의 크리에이티브 스튜디오, 1F는 콘크리트·벽면 차트 장식·커피 바의 채널 컨트롤룸이다. 각 층은 별도 회의실을 유지한다. 층 버튼과 스크롤로 이동하고 +/−로 확대한다.

채광은 `실제 시간 / 밝은 낮 / 노을 / 도시의 밤`에서 선택한다. 실제 시간 모드는 브라우저 현지 시간으로 낮·노을·밤을 계산한다. 밤에는 도시 창문 불빛·달·별과 실내의 따뜻한 조명을 표시하고 오피스 UI도 어둡게 바꾼다. 오피스를 닫으면 리포트 테마로 돌아간다. 창밖 배경은 도시 파노라마·리버뷰 두 가지이며 날씨는 맑음·흐림·비·눈을 고를 수 있고 창문 안뿐 아니라 건물 바깥 하늘·여백·층 사이에도 적용된다(눈은 층 경계에 쌓임). 화면 하단의 알약형 층 버튼(`전체 층`, `4F`~`1F`)으로 보기를 바꾼다. 전체 층은 업무석 위주의 요약 단면이고, 한 층을 고르면 그 층 아래에 추가 공간이 펼쳐진 상세 평면을 보여준다(4F 전사 대회의실·임원 라운지·스카이 바, 3F 자료 서고·전략 회의실·리딩 누크, 2F 제품 컷 촬영 스튜디오·편집실·크리에이티브 회의실, 1F 리셉션·공용 좌석·타운 키친). 추가 공간은 연출이며 세션을 만들거나 표시하지 않는다.

`전체 회의`를 누르면 현재 작업 중이 아닌 캐릭터들이 엘리베이터를 거쳐 최상층 타운홀 라운지로 모인다. `회의 마치기`로 원래 부서로 돌아간다. 회의는 공간 연출이며 실제 Codex 작업을 만들거나 중지하지 않는다. 회의 중 새 작업이 연결된 담당자는 작업 부서로 돌아간다.

야경 프리뷰: http://127.0.0.1:8000/virtual-office-preview.html?lighting=night&view=river

추가 디자인 검증: `node dashboard/tests/office-design.cjs` (시간 전환, 배경 차이, 회의 모임·복귀, 진행 작업 유지, 반응형 컨트롤).

Habblaud의 MIT 아트 모듈을 번들링해 가구·캐릭터·포즈·바닥을 그린다. 출처 커밋, 재빌드 명령과 MIT 고지는 `tools/habblaud/README.md`, `tools/habblaud/LICENSE`에 보관한다. Habblaud 서버, World 서비스, 전역 Codex hooks는 사용하지 않는다.

참고 영상은 watch의 Gemini 서버가 HTTP 503을 반환해 분석하지 못했다. 구현은 사용자의 공간·인테리어·동작 요구와 Habblaud 공식 소스를 기준으로 했다.

## AI 회의실

상단 `AI 회의 열기`로 주제를 입력해 회의를 연다. 팀별 에이전트가 4F에 모이고, 실제 Codex 회의 발언(`@@팀:` 형식 줄)만 말풍선으로 표시한다. 대표 채팅은 Happier 세션에 암호화해 전달한다. `회의 마치기`를 누르면 팀장이 `docs/meetings/`에 정리본을 쓰고 main에 push한다. 테스트: `node dashboard/tests/ai-meeting.cjs`. 결정 기록: `docs/decisions/2026-11-18-ai-meeting-room.md`.

## 5F 대강당 · AI 품평회

5F 대강당에 처음 들어가면 설정 팝업에서 발표 주제, 산출물(마케팅 브리핑·광고 이미지·영상), 평가 에이전트 수, 에이전트별 관점·모델·Effort를 고른다. 에이전트마다 별도 Codex 세션이 발표 → 관점별 피드백 → 답변 순서로 실행된다. 대강당 화면에 산출물을 띄우고, 대표 채팅으로 참여한다. `세션 종료`를 누르면 `docs/reviews/`에 정리한다. 테스트: `node dashboard/tests/ai-review.cjs`. 결정 기록: `docs/decisions/2026-11-18-ai-review-hall.md`.
