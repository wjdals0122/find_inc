# Habblaud art integration

MIT pixel-art renderer from https://github.com/marmottajr/habblaud at faa1a012b5fbf632c66dc6801c5383e53a542406.
Only the browser art module and its transitive sources are included. No Habblaud World service or Claude/Codex hooks are installed. FIND.INC uses its existing authenticated Happier Cloud adapter for dashboard-launched Codex tasks.

Build from repository root:
```powershell
node dashboard/tools/habblaud/build.cjs
```
