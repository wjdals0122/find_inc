# Instagram Insights 조회 결과

- 조회 일시: 2026-11-17T11:43:46+09:00
- 요청 기간: 2026-11-10 ~ 2026-11-16 (최근 완료된 7일)
- 인증 출처: Instagram 채널 폴더의 .env (값 비공개)
- 결과: 인증 실패로 Insights 조회 불가

Instagram Graph API의 계정 조회와 Facebook Graph API의 계정 조회 모두 HTTP 401, OAuthException 코드 190을 반환했다. Instagram 응답은 `Invalid OAuth access token - Cannot parse access token`이었다. 계정 조회가 인증 단계에서 실패하여 Insights 수치를 가져오지 못했다. 데이터가 0이라는 의미는 아니다. 토큰 접두사만으로 로그인 방식을 판정하지 않았다.

기존 연결의 유효한 액세스 토큰을 로컬 .env에 설정한 뒤 계정 조회와 Insights 권한을 다시 확인해야 한다. 토큰, 요청 URL, 응답 원문은 저장하지 않았다. 계정이나 게시물은 변경하지 않았다.
