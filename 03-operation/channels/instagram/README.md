# Instagram 채널

Instagram 연동 기능과 운영 자료를 이 폴더에서 관리한다.

- 연동 기능: API 연동 코드, 설정 예시와 사용 안내.
- 운영 자료: 게시 계획, 운영 기록과 성과 분석.

공통 저장 규칙은 [채널 관리 가이드](../../../docs/guides/channel-management.md)를 따른다.

## 인증 정보

- 액세스 토큰은 이 폴더의 `.env` 파일에 있는 `INSTAGRAM_ACCESS_TOKEN`에 저장한다.
- `.env`는 Git에 포함하지 않는다.
- 토큰 값은 채팅, 로그, 명령 출력과 문서에 노출하지 않는다.
