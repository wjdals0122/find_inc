# 채널 연동 기능과 운영 자료 관리

채널별 연동 기능과 운영 자료는 프로젝트 최상위 `03-operation/channels/` 아래의 해당 채널 폴더에서 관리한다.

| 채널 | 저장 위치 |
| --- | --- |
| Instagram | `03-operation/channels/instagram/` |
| YouTube | `03-operation/channels/youtube/` |
| 랜딩 페이지 | `03-operation/channels/landing-page/` |

- API 연동 코드, 설정 예시와 사용 안내는 해당 채널 폴더에 둔다.
- 게시·배포 계획, 운영 기록과 성과 분석도 해당 채널 폴더에 둔다.
- 콘텐츠 제작 원본은 기존 `02-contents/`의 Google Drive 관리 방식을 유지하고, 운영 자료에서 필요하면 원본 링크를 참조한다.
- 실제 인증 토큰, 비밀번호와 비밀 키는 커밋하지 않는다. 설정 예시에는 실제 비밀값을 넣지 않는다.
