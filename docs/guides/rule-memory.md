# 규칙 기억 가이드

- 사용자가 앞으로 지킬 규칙을 기억해달라고 하면 규칙을 `docs/guides/`의 관련 가이드에 정리한다. 관련 가이드가 없으면 새로 만든다.
- `AGENTS.md`의 `# 회사 규칙` 아래에 해당 가이드 링크와 짧은 준수 지시를 추가한다.
- 기존 가이드와 규칙을 확인해 중복되는 내용을 합치고, 관련 없는 내용은 유지한다.
- 요청한 규칙이 기존 규칙과 충돌하면 수정하기 전에 사용자에게 확인한다.
- 중요한 결정은 `docs/guides/decision-recording.md`에 따라 `docs/decisions/`에 기록한다.
- 작업을 마치면 변경한 파일을 사용자에게 알린다.
