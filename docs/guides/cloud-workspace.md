# 클라우드 작업 경로와 프로젝트 스킬

- 클라우드 환경에서는 `/workspace/` 아래의 대상 프로젝트 폴더를 작업 기준으로 삼는다. 현재 `wjdals0122/find_inc` 저장소의 작업 기준은 `/workspace/find_inc`이다.
- 작업 전에 대상 저장소와 프로젝트 루트의 `AGENTS.md`, 작업 경로에 적용되는 추가 지침을 확인한다. 파일 탐색·명령 실행·상대 경로 해석은 해당 프로젝트 루트를 기준으로 한다.
- 사용자가 `/watch`, `/remember` 등 스킬을 요청하면 먼저 프로젝트의 `.agents/skills/`에서 해당 스킬의 `SKILL.md`를 찾아 읽고 적용한다. 대화에 표시된 스킬 목록에 없다는 이유만으로 프로젝트 스킬을 사용할 수 없다고 판단하지 않는다.
- 스킬의 스크립트와 참조 문서는 해당 스킬 디렉터리를 기준으로 실제 경로를 확인해 사용한다. 스킬이 지정한 엔진·설정·제약을 따른다.
- 예상 위치에 스킬이 없으면 프로젝트의 `.agents/skills/` 안에서 이름과 경로를 검색한다. 끝내 찾지 못하면 누락 사실과 확인한 경로를 알리며, 존재하지 않는 스킬을 적용했다고 말하지 않는다.
