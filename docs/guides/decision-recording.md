# 결정 기록 가이드

- 대화에서 중요한 결정이 확정되면 `docs/decisions/YYYY-MM-DD-주제.md`에 기록한다.
- 날짜, 결정 내용, 이유를 짧게 적는다.
- 이유는 대화에서 확인된 내용만 적고, 지어내지 않는다. 이유가 확인되지 않으면 `확인되지 않음`으로 적는다.
- 단순한 제안이나 미정 사항은 기록하지 않는다.

## 기록 형식

```markdown
# 결정: 주제

- 날짜: YYYY-MM-DD
- 결정 내용: 확정된 결정을 짧게 적는다.
- 이유: 대화에서 확인된 이유를 짧게 적는다. 확인되지 않으면 "확인되지 않음"으로 적는다.
```
