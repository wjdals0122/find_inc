# 결정: 스킬 실행 아일랜드

- 날짜: 2026-11-18
- 결정 내용: 기존 스킬 버튼을 화면 오른쪽 아래의 고정 아일랜드로 옮긴다. 마우스를 올리거나 키보드로 접근하면 프로젝트 스킬 목록이 순서대로 펼쳐진다. 아이콘을 누르면 기존 실행 창을 열고, 목록의 스킬을 누르면 해당 스킬을 선택해 연다. 터치 환경에서는 아이콘을 눌러 실행 창을 연다.
- 이유: 사용자가 제공한 플로팅 아이콘 예시처럼 스킬 목록을 애니메이션으로 펼치고 기존 실행 팝업으로 연결해달라고 요청했다.
- 보존: 기존 Happier 연결 확인, 모델·Effort 선택, 실행 상태와 히스토리, 대시보드 반영 기능을 유지한다. 이번 변경은 localhost 프리뷰에 우선 반영한다.
