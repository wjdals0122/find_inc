# 결정: YouTube Data API 연결

- 날짜: 2026-11-16
- 결정 내용: 사용자가 제공한 데스크톱 OAuth 클라이언트로 YouTube 채널 및 댓글 권한을 승인받는다. 인증 정보와 토큰은 `03-operation/channels/youtube/.private/`에 보관하고 Git에서 제외한다. 폴더 접근 권한을 제한하며 토큰은 Windows 사용자 계정에 묶인 DPAPI로 암호화한다. 연결 검증은 채널·댓글 읽기 조회로만 수행하고 인증 정보·토큰을 채팅이나 로그에 출력하지 않는다.
- 이유: 사용자가 자신의 YouTube 채널 연결과 안전한 인증 정보 보관을 요청했다.
