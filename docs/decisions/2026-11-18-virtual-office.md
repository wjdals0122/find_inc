# 결정: 대시보드 버추얼 오피스 추가

- 날짜: 2026-11-18
- 결정 내용: 기존 대시보드에 Habblaud 기반 픽셀아트 버추얼 오피스를 추가한다. 상단 버튼으로 전환하고, 대시보드에서 실행한 Codex 스킬 작업을 담당 에이전트별 캐릭터에 연결한다. 부서별 층·하위 부서 파티션·엘리베이터·라운지·회의실·도시뷰·시간과 날씨 연출을 구성한다. Computer Use는 사용하지 않고 localhost 프리뷰를 먼저 제공한다.
- 이유: 사용자가 대시보드에서 실행한 작업의 진행 상황·결과·오류를 오피스에서 볼 수 있도록 요청했다. 밝은 도시뷰와 세련된 모던 인테리어를 요청했다.

## 층별 디자인과 야경 확장

- 결정 내용: 각 층을 서로 다른 인테리어로 바꾸고, 선택형 밤 모드·도시 야경·리버뷰와 전사 회의를 위한 대형 타운홀 라운지를 추가한다.
- 이유: 사용자가 층마다 다른 디자인, 첨부 영상과 같은 공간, 야경 배경 버전, 밤 기능과 전체 회의 라운지를 요청했다.
