# 결정: AI 회의실 추가

- 날짜: 2026-11-18
- 요청: 대시보드와 버추얼 오피스에 AI 회의실을 추가한다. 주제를 입력해 회의를 열면 전략·콘텐츠·운영팀 에이전트가 회의실에 모이고, 기존 Happier 연결로 Codex 멀티 에이전트 회의를 실행한다. 대표가 채팅으로 참여하고, `회의 마치기` 시 팀장이 정리본을 `docs/`에 저장해 main 브랜치에 push한다.
- 결정:
  - 대시보드 상단에 주제 입력창과 `AI 회의 열기` 버튼을 둔다(모바일은 `AI` 아이콘 버튼). 회의 창은 우측 하단 패널로 띄운다.
  - 회의는 Codex 세션 하나로 실행한다. 진행자(팀장)는 가능하면 하위 에이전트로 전략·콘텐츠·운영 팀장을 띄우고, 모든 발언을 `@@팀장/전략/콘텐츠/운영: ...` 형식으로 남긴다. 이 형식의 줄만 말풍선과 대화 기록에 표시하므로, 말풍선은 실제 회의 발언이다.
  - 대표 발언은 Happier 세션 pending 큐(`POST /v2/sessions/:id/pending`)에 세션 키로 암호화해 전달한다. 프로토콜은 로컬 Happier CLI 0.2.21 구현을 따랐다.
  - 오피스에서는 각 팀에서 작업 중이 아닌 대표 캐릭터 1명씩과 디렉터(팀장), `나 (대표)`가 4F에 모인다. 작업 중인 캐릭터는 자리를 지킨다. 회의가 끝나면 원래 부서로 돌아간다.
  - `회의 마치기`를 누르면 팀장이 `docs/meetings/YYYY-MM-DD-<주제>.md`를 작성한다. 현재 작업 브랜치와 커밋하지 않은 변경은 건드리지 않고, 임시 git worktree에서 그 파일만 main에 커밋·push한 뒤 원격 반영을 확인한다.
  - 회의 중 에이전트는 파일 읽기만 한다. Git push 같은 권한 요청은 Happier 승인 대기로 표시된다.
- 검증: `dashboard/tests/ai-meeting.cjs`(프리뷰 샘플 전송) 통과, `auth.cjs`(상단 버튼 포함), `virtual-office.cjs`, `office-design.cjs`, Happier 클라이언트 단위 테스트 13개 통과. Computer Use는 사용하지 않았다.
- 제한: 실제 Happier/Codex 세션으로 회의를 실행해 보지는 않았다. 메시지 조회는 최근 100개 기준이다. 프리뷰(`virtual-office-preview.html`)의 회의는 `[샘플]` 표시가 붙은 대본이며 저장·push하지 않는다.
