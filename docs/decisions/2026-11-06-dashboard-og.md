# 결정: 대시보드 링크 공유 미리보기

- 날짜: 2026-11-06
- 결정 내용: 대시보드 HTML에 제목·설명·정적 Open Graph 및 Twitter 카드 태그를 설정한다. 조사한 BMW X5·LG 퓨리케어 이미지와 브랜드 로고로 1200 × 630, 1200 × 1200 썸네일을 구성한다. Firebase Hosting과 GitHub `main`에 반영한다.
- 이유: 사용자가 링크 공유 시 제목·설명·썸네일을 표시하고 가로형과 1:1 비율에서도 잘 보이도록 제작한 뒤 Hosting과 `main`에 업로드해달라고 요청했다.
- 표시 제목: FIND.INC | 브랜드·상품 전략 대시보드
- 접속 주소: https://find-inc.web.app/
- 보존 범위: 기존 로그인·보고서 데이터·프로필·CSS·실행 코드를 유지한다. 기본 썸네일의 핵심 내용을 중앙 정사각형 크롭 영역 안에 배치한다.

## 썸네일 수정

- 결정 내용: 사이트 밝은 모드의 배경과 파란색 포인트를 사용하고, FIND.INC를 크게 강조한다. 아래에는 BMW·LG전자·토스·카카오·신한은행을 나열한다. 가로형과 정사각형을 함께 수정하고 `light-v2` 이미지 주소로 교체한다.
- 이유: 사용자가 기존 썸네일 대신 밝은 모드와 어울리는 디자인, 큰 FIND.INC 문구와 하단 브랜드명 목록을 요청했다.
