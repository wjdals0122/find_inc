# 결정: Flutter Contents와 Google Drive 연결

- 날짜: 2026-11-19
- 결정 내용: 기존 웹 Contents의 Google Drive 루트 폴더를 Flutter 네이티브 Contents 화면에 연결한다. 제공받은 Marketing Dashboard OAuth 클라이언트의 공개 ID를 사용하고 Firebase 로그인과 Drive 계정 연결을 구분한다. 기존 Strategy는 유지한다.
- 이유: 사용자가 기존 Contents 디자인과 Google Drive API 연동을 요청하고 플랫폼 클라이언트 설정 파일을 제공했다.
