# 결정: 전략 대시보드 Firebase 로그인

- 날짜: 2026-11-05
- 결정 내용: 기존 `01-strategy/dashboard/dashboard.html`에 수집한 브랜드 로고의 궤도 애니메이션을 활용한 로그인 화면을 추가한다. `find-inc` 프로젝트의 이메일·비밀번호 인증에 성공하면 기존 대시보드를 표시하며 상단바에 로그아웃을 제공한다. 기존 보고서 데이터와 디자인을 보존하는 단일 HTML 방식으로 구현한다.
- 이유: 사용자가 첨부한 로그인 화면 예시를 수집된 브랜드 로고로 변경하고 Firebase 로그인·로그아웃을 연결해달라고 요청했다.
- 구현 범위: HTML에 포함된 자료의 서버 측 접근 제한은 별도 작업이다. 이번 수정은 로그인에 따른 화면 전환을 구현하며 웹 공개 배포는 포함하지 않는다.
